# Convexa Color Palette

## Direction
Bright, spacious, premium visual system with semantic market coloring.

## Core Roles
- Bull (optimistic): vibrant blue-purple spectrum
- Bear (cautious): warm red-orange spectrum
- Neutral base: clean white and soft gray layering
- Accents: bright green for victory, soft amber for caution

## Palette

### Bull
- Bull 500: #3f70ff
- Bull 600: #3159db
- Bull purple accent: #7a5cff

### Bear
- Bear 500: #f3653a
- Bear 600: #d94f2a
- Bear orange accent: #ffb347

### Neutral
- Background: #fcfdff
- Surface: #ffffff
- Surface alt: #f7f9fc
- Border subtle: #e1e7ef
- Text primary: #1a1f2b
- Text secondary: #556176

### Alerts and Wins
- Victory: #18c46b
- Caution: #f0b35f
- Danger: #ea4f4f
- Info: #33a3ff

## Supporting Tokens
- Spacing: 8px base grid (8, 16, 24, 32, ...)
- Typography weights: 400, 500, 600, 700
- Shadows: subtle layered shadows with low opacity
- Corner radius: 8px as default medium radius

## Usage Guidance
- Bull cards should anchor with blue and only use purple as an accent.
- Bear cards should anchor with warm red and use orange for confidence/volume indicators.
- Keep base sections mostly neutral with strong whitespace to preserve readability.
- Reserve green and amber for status signals rather than decorative usage.
