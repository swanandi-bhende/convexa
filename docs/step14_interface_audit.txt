Discrepancies resolved
- run_bull_round, run_bear_round, and run_judge_round now take session_id as the first argument so the orchestrator can persist consistent session-scoped traces.
- Dry-run control is now pushed into each imported module through set_dry_run(value: bool).
- Stake validation now reads DebateEscrow.getStakeInfo() instead of a placeholder zero-stake path.
- Orchestrator startup now bootstraps AXL nodes, opens the stake window, and only then enters the round loop.
